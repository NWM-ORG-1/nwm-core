## 1. 시세 (티커·기사 차트)

### 핵심 결론
- **국내 주식·지수(코스피·코스닥)는 지연 시세라도 공개 화면에 띄우려면 라이선스가 필요합니다.** 거래소(KRX) 승인 → 코스콤 일반 정보이용계약. 무료 예외를 찾지 못했습니다.
- **증권사 OpenAPI(한국투자·키움·LS)는 본인 투자용**이라 제3자 화면 재표시가 금지됩니다. KRX OPEN API(일별)도 비상업·제3자 제공 금지.
- **미국 지수(S&P 500·다우·나스닥)도 지수 자체의 별도 라이선스**가 필요합니다(지연이어도).
- **국내 거래소(업비트·빗썸·코인원·코빗)와 바이낸스 API 시세는 서면 동의 없이 재배포 금지**입니다.
- **무료로 안전한 것:** 원/달러 일일 고시(수출입은행 API, 이용 제한 없음), 미 국채 10년 일일 금리(미 재무부 XML, 공공저작물), DeFi 지표(DefiLlama — 약관 최종 확인 필요).
- **코인 시세는 CoinGecko 유료 플랜(Basic 월 $35, 연간 결제 시 $29)** 이 공개 표시를 허용합니다(출처 표기). 무료 Demo는 표시 불가.

## 2. 소셜 · 커뮤니티

### 텔레그램 (지정 채널)
| 방법 | 비용 | 특징 | 위험 |
|---|---|---|---|
| `t.me/s/<채널>` 공개 미리보기 (또는 자체 RSSHub) | 0 | 로그인 불필요, 공개 채널만, 이미지까지 | 낮음–중간, 가끔 실패 |
| 봇 API (채널 관리자가 봇을 관리자로 추가) | 0 | 비공개 채널도 가능, 동의 기반 | 낮음 |
| MTProto 사용자 계정 (Telethon 등) | 0 + 전화번호 | 전부 읽기 가능 | 중간 — 계정 감시·차단 위험 |

- **중요:** 텔레그램 약관은 동의 없이 수집한 데이터를 **AI/ML에 쓰는 것을 금지**합니다. 편집자 알림용 수집은 괜찮지만, **LLM으로 텔레그램 글을 채점하는 센티먼트 지수는 채널 운영자의 서면 동의**가 필요합니다. 규칙 기반 집계(게시량·조회수·키워드)는 위험이 낮습니다.
- 채널 글을 그대로 보여주는 공개 미러를 만들면 텔레그램 스폰서 메시지 노출 의무가 생깁니다 → 미러는 만들지 않습니다.

### X (트위터)
- 2026년부터 셀프서비스는 **사용량 과금(PPU)** 만 있습니다: 게시물 읽기 **$0.005/건**, 같은 게시물은 하루 1회만 과금, 빈 응답은 무료, 지출 상한 설정 가능.
- 비용은 폴링 빈도가 아니라 **읽는 게시물 수**에 비례합니다.

| 계정 수 | 계정당 하루 글 | 월 게시물 | 월 비용 |
|---|---|---|---|
| 30 | 10 | 약 9,000 | 약 $45 |
| 100 | 15 | 약 45,000 | 약 $225 |
| 100 (매우 활발) | 30 | 약 90,000 | 약 $450 |

- 서드파티 스크래핑 API(twitterapi.io, SocialData 등)는 더 싸지만 **X 약관의 스크래핑 금지 위반**이며, 위반을 "유도·조력"한 쪽도 연대 책임(100만 건당 $15,000 손해배상 예정)이 있습니다 → 비추천.
- 화면에 X 글을 보여줄 때는 **공식 임베드**(무료, 무제한)를 씁니다. 직접 렌더링하면 원문 그대로 + 이름·핸들·아바타·시각·X 로고가 필요하고, X에서 삭제된 글은 우리 쪽에서도 지워야 합니다.

### 레딧
- **2026-10-31 신규 API 신청 마감**, 11-13 RSS 종료, 2027년 3월 공개 API 종료. 무료 등급은 비상업 전용, 상업 이용은 별도 서면 승인.
- 추천: 쓰지 않거나, 라이선스 집계 업체를 통해서만.

### 국내 커뮤니티 (네이버 종토방, 디시, 클리앙, 뽐뿌, FM코리아)
- 공개 API가 없고, 디시·네이버 약관은 자동 수집을 금지합니다. 네이버는 종토방 API를 증권사에 **유료**로 제공합니다.
- 판례 흐름이 불리합니다: 2024 대법원 2023도17354(DB 복제 유죄), 2025.12 특허법원 2024나11433(네이버 v. 다윈 — **공개된** 매물 정보 크롤링도 DB권 침해, 8천만 원 배상). 2022 야놀자 v. 여기어때는 형사 무죄였으나 민사에서는 배상 판결.
- **크롤링은 숫자만 세더라도 반복 복제에 해당**해 위험합니다.
- **대안 (위험 낮음):** 라이선스 집계 서비스 **썸트렌드**(X·블로그·인스타·커뮤니티·뉴스, Starter 월 ₩15만 / Pro ₩50만 / Business ₩100만) + **네이버 데이터랩 검색어 트렌드 API**(무료, 하루 1,000회).

### 인용·저작권 (실무 원칙)
- 저작권법 제28조: 보도를 위한 **정당한 범위의 인용**은 허용(우리 기사가 주, 인용이 종). 출처 표시 의무(제37조). 사실 전달에 불과한 시사보도는 보호 대상이 아님(제7조 5호).
- 짧게 인용 + 출처 표기, **사진·영상은 재업로드하지 않고 링크·공식 임베드**.
