# 무료 API 키 발급 안내 (2026-10)

키가 있어야 받을 수 있는 1차 자료 네 곳입니다. 어느 것도 돈이 들지 않습니다.

## 공통

- **키는 Railway에만 넣습니다.** nwm-core 프로젝트 → `worker` 서비스 → Variables에 아래 이름으로 추가합니다. 채팅·문서·코드에는 붙여 넣지 않습니다.
- 넣으면 워커가 다시 배포되고, 그 키를 쓰는 소스의 ‘키 필요’ 표시가 사라집니다.
- 발급 화면의 활용 목적은 이렇게 적으면 됩니다: “인터넷신문 뉴웹미디어(newweb.media)의 보도용 자료 수집, 하루 수백 회 이하 조회”.
- 키를 넣었다고만 알려 주시면(키 값은 빼고) 해당 API를 `json.list` 소스로 붙이고, 싱가포르(Railway)에서 시험 수집해 확인합니다.

| 변수 이름 | 어디 | 무엇이 들어오나 |
|---|---|---|
| `DATA_GO_KR_KEY` | 공공데이터포털 | 관보, 나라장터 입찰공고, 정책브리핑 정책뉴스, 부처별 보도자료 |
| `ASSEMBLY_API_KEY` | 열린국회정보 | 의안 접수·발의 법률안·계류 의안·국회 일정·입법예고 |
| `LAW_OC` | 법제처 국가법령정보 | 그날 바뀐 법령, 행정규칙, 헌재 결정례 (전용 어댑터 필요, 아래 3번) |
| `CONGRESS_API_KEY` | Congress.gov | 미국 의회 법안 진행 |

## 1. 공공데이터포털 (data.go.kr) — `DATA_GO_KR_KEY`

1. data.go.kr 회원가입. 개인회원은 만 14세 이상 내국인이고 휴대폰이나 아이핀으로 본인확인을 합니다. 사업자등록이 있으면 기업회원으로 가입해도 됩니다.
2. 아래 데이터를 하나씩 검색해 **활용신청**을 누르고 활용 목적을 적습니다. 키는 계정에 하나지만 신청은 API마다 따로 해야 합니다. 세 가지 모두 자동승인으로 안내돼 있습니다.

   | 번호 | 이름 | 이용 조건 |
   |---|---|---|
   | 15109157 | 행정안전부_관보 목록 정보 | 제한 없음 |
   | 15129394 | 조달청_나라장터 입찰공고정보서비스 | 제한 없음 |
   | 15095335 | 문화체육관광부_정책브리핑_정책뉴스 | 공공누리 1유형. 출처를 “자료출처=정책브리핑 www.korea.kr”로 표시하고, 사진은 쓰지 않습니다 |

   과기정통부(15074632), 중기부(15113299), 외교부(15141564)처럼 부처별 보도자료 API도 같은 키로 신청합니다.
3. 마이페이지 → 데이터활용 → Open API → 인증키 발급현황에서 **일반 인증키(Decoding)** 를 복사해 Railway에 넣습니다. 같은 키가 Encoding과 Decoding 두 형태로 보이는데, 우리 수집기가 주소를 직접 인코딩하므로 Decoding을 씁니다.
4. 승인 직후에는 “SERVICE KEY IS NOT REGISTERED” 오류가 날 수 있습니다. 1–2시간 지나면 풀린다는 안내가 많습니다.

- 하루 한도는 개발계정 기준 1,000회 또는 10,000회입니다. 모자라면 활용사례를 등록하고 운영계정으로 늘려 달라고 신청합니다.
- 정책브리핑 RSS는 2026-07-01에 중단됐습니다. 전 부처 ‘보도자료’ API는 찾지 못했습니다. 옛 `pressReleaseService`는 “없는 서비스”로 응답한다는 보고가 있습니다. 그래서 정책뉴스 API와 부처별 보도자료 API를 씁니다.

## 2. 열린국회정보 (open.assembly.go.kr) — `ASSEMBLY_API_KEY`

1. 국회 통합회원(member.assembly.go.kr)에 가입합니다. 아이핀이나 휴대폰 본인확인이 필요합니다.
2. open.assembly.go.kr에 로그인한 뒤 마이페이지에서 **인증키 발급**을 누릅니다. 심사 없이 바로 나오고, 키는 10개까지 만들 수 있습니다.

- 키 없이 ‘sample’로 부르면 10건만 나옵니다. 하루 한도는 공개돼 있지 않고, 지나치게 자주 부르면 제한될 수 있습니다.
- 출처는 “열린국회정보, 서비스 메뉴명, 날짜”로 표시합니다(이용약관 제7조).
- 붙일 수 있는 것: 의안 접수 목록, 의원 발의 법률안, 계류 의안, 최근 본회의 처리 의안, 국회 일정, 입법예고. AI·가상자산·스테이블코인 법안이 발의되는 순간을 잡는 용도입니다.

## 3. 법제처 국가법령정보 공동활용 (open.law.go.kr) — `LAW_OC`

1. open.law.go.kr에 가입합니다. 아이디(이메일 주소), 이름, 연락처, 소속기관명(뉴웹미디어)을 적습니다.
2. 시스템 정보에 **도메인 `newweb.media`** 와 서버 IP를 등록합니다(아래 ‘주의’).
3. OPEN API → 활용신청에서 쓸 API를 고릅니다. 법령 변경이력, 행정규칙, 헌재 결정례를 신청하면 됩니다. 가입 화면은 자동승인이라고 하고 이용 안내는 담당자 승인에 1–2일이라고 해서, 둘 중 어느 쪽인지 확인하지 못했습니다.
4. OC 값은 아이디 이메일의 `@` 앞부분입니다. 이것을 Railway에 `LAW_OC`로 넣습니다.

**주의 — 서버 확인:** 법제처는 부르는 서버의 IP와 도메인이 등록된 것과 맞는지 봅니다. Railway의 출구 IP는 기본적으로 고정되지 않습니다. 방법은 두 가지입니다.

- **도메인만 등록하고 요청에 `Referer: https://newweb.media`를 보냅니다.** 고정 IP 없이 통과했다는 개발자 보고가 있지만 공식 안내는 아닙니다.
- **Railway Pro의 고정 출구 IP를 씁니다.** 서비스 Settings → Networking → Enable Static IPs를 켜고 다시 배포한 뒤, 나오는 IP 3개를 등록합니다. Pro 요금제에서만 됩니다.

법제처는 어느 방법인지 정한 뒤 전용 어댑터를 붙여야 해서, 지금은 키 자리만 안내합니다.

## 4. Congress.gov (api.congress.gov) — `CONGRESS_API_KEY`

1. api.congress.gov/sign-up에 이름과 이메일을 적으면 api.data.gov 키가 메일로 바로 옵니다.

- 한도는 시간당 5,000회입니다. 넘기면 약 한 시간 막힙니다.
- 붙일 것: 미국 의회 법안 진행. 디지털자산 시장구조법, 스테이블코인, AI 관련 법안을 봅니다. 연방관보 규칙은 키 없이 이미 받고 있습니다(`fedreg-*` 소스).

## 확인하지 못한 것

- 열린국회정보: 하루 호출 한도, 본인확인 없이 가입할 수 있는지.
- 법제처: IP 칸이 필수인지, 도메인만으로 되는지(공식), 지금 승인에 걸리는 시간, 상업 이용을 막는 API가 어느 것인지.
- 공공데이터포털: 키가 동기화되는 데 걸리는 시간(1–2시간은 이용자들의 경험담), 개발계정 유효기간.
- 한국 정부 API(관보·법제처)가 싱가포르에서 잘 열리는지. 키가 생기면 Railway에서 먼저 시험합니다.

조사 출처: 각 기관 이용 안내 페이지(검색 결과 발췌)와 2026년 개발자 공개 저장소의 기록. 이 문서를 쓴 세션에서는 기관 사이트에 직접 접속할 수 없어 화면을 열어 보지는 못했습니다.
